# 🔧 Device Repair Pro

Welcome to Device Repair Pro!  
A modern and simple web application designed to manage and present device repair services efficiently. Built using Node.js, Express.js, HTML, CSS, and JavaScript.

---

## 🚀 Live Demo

👉 Add your live link here  
Example: https://device-repairpro.onrender.com (not for mobile)

---

## 🌟 Website Sections

- 🏠 Home – Introduction and overview of services  
- 🛠 Services – List of available repair services  
- ℹ️ About – Information about the company and experience  
- 📞 Contact – Easy way for customers to reach out  
- ⚙️ Admin Panel (optional) – Manage requests and services  

---

## ⚡️ Features

- 🎨 Clean and modern UI design  
- 📱 Fully responsive layout (mobile, tablet, desktop)  
- ⚡️ Fast and lightweight performance  
- 🧩 Service management system  
- 🔗 Simple navigation structure  
- 🚀 Backend powered by Express.js  

---

## 🛠 Technologies Used

- HTML5 – Structure  
- CSS3 – Styling & responsive design  
- JavaScript – Frontend logic  
- Node.js – Backend runtime  
- Express.js – Server framework
